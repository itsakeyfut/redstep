# redstep-macros

Procedural macros for the [redstep](https://crates.io/crates/redstep)
security-testing framework.

This crate is an implementation detail of redstep and is not meant to be used on
its own. See the [redstep crate](https://crates.io/crates/redstep) and the
[repository](https://github.com/itsakeyfut/redstep) for documentation.
